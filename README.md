# Tricell-Encryption-Algorithm-2.0
## Beskrivning och Bakgrund
Det här repot tillhör ett projekt på högskolenivå med målet att lära oss hur kryptering fungerar. Projektet bygger på att utveckla en algoritm som ska kryptera meddelanden man sedan skickar mellan de andra grupperna i klassen. På grund av att det här är under årskurs 1 så rekommenderas inte att algoritmen används i professionella sammanhang utan mera för att se hur man kan tänka. Projektet kommer att genomföras i JavaScript

## Filer
* README.md innehåller information och beskrivning om projektet
* Psudocode.txt är en beskrivning av algoritmen i form av psuedokod att utgå från när man ska bygga den
* encryption.php är ifall man vill testa en grundläggande version av krypteringen i terminalen. Den är gjord i php och kommer skrivas om i ett senare skede

## Hur man kör encryption.php
* Ta en git clone genom "git clone https://github.com/Codercat314/Tricell-Encryption-Algorithm-2.0/"
* byt till korrekt mapp med "cd .\Tricell-Encryption-Algorithm-2.0\"
* kör filen med "php .\encryption.php"
* PHP 8.3.6 ska fungera
* Alternativt kan man köra den med coderunner i visual studio code
